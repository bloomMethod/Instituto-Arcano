# Instituto Arcano

🌐 **Voir site web:** 
[Visiter Instituto Arcano](https://bloomMethod.github.io/Instituto-Arcano/)

📌 Description

Instituto Arcano est un site web conçu pour présenter une école de haute magie blanche proposant des formations ésotériques, des consultations spirituelles, des cours de tarot et des séminaires spécialisés.

Le site permet aux visiteurs de découvrir les différents services de l'institut, de consulter les formations disponibles et de trouver les moyens de contact et de réservation.

🚀 Fonctionnalités

- Présentation de l'Institut Arcano.

- Navigation avec menu responsive et menu hamburger.

- Présentation des services et consultations spirituelles.

- Section dédiée aux cours et formations spécialisées.

- Présentation des séminaires disponibles.

- Carrousels interactifs pour parcourir les services, formations et réservations.

- Section actualités et nouveautés.

- Informations de contact et de réservation.

- Accès aux moyens de paiement et aux contacts WhatsApp.

📚 Services proposés

- Consultations spirituelles.

- Tarot et astrologie.

- Formations ésotériques.

- Cours de magie blanche.

- Séminaires spécialisés.

- Rituels et accompagnement spirituel.

🛠️ Technologies utilisées

- HTML5

- CSS3

- JavaScript

💻 Installation

- Cloner le dépôt GitHub.

- Ouvrir le dossier du projet dans Visual Studio Code.

- Vérifier que les dossiers CSS, JS et images sont correctement organisés.

- Ouvrir le fichier index.html dans un navigateur.

📱 Responsive Design

Le site intègre une navigation adaptée aux appareils mobiles, avec un menu hamburger et des carrousels pour faciliter la navigation sur les petits écrans.
